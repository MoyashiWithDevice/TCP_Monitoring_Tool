# eBPF を用いた TCP 再送イベント可視化ツール

## 概要

本プロジェクトは、Linux カーネル内で発生している **TCP の再送（Retransmission）イベント** を  
eBPF を用いてリアルタイムに取得し、ユーザーランドで可視化するツールを作成することを目的とする。

アプリケーションログや通常のパケットキャプチャからは見えない、  
**カーネル TCP スタック内部の実際の再送挙動** を観測可能にする。

---

## 背景

現代のネットワークは安定していると考えられがちだが、実際には以下のような環境で  
TCP の再送は頻繁に発生している。

- WiFi / モバイル回線
- Docker / NAT / Overlay Network
- クラウド間通信
- 混雑したネットワーク経路

しかし、これらの再送はカーネル内部で処理されるため、  
通常のログやアプリケーションレベルからは観測できない。

本ツールにより、

> 「実際にどれだけ TCP 再送が発生しているか」

を可視化する。

---

## 目的

- TCP 再送イベントをリアルタイムに取得する
- 再送の発生元 IP / ポート / プロセスを特定する
- 再送発生頻度を集計する
- 時系列で可視化できるデータを出力する

---

## 技術構成

| レイヤ | 技術 | 役割 |
|---|---|---|
| カーネル | eBPF (C) | TCP 再送関数へ kprobe を設置 |
| ユーザーランド | Go | eBPF からイベントを受信 |
| 集計 | Go | 再送イベントの統計処理 |
| 可視化 | CLI / Prometheus | データの表示・外部連携 |

---

## フック対象となるカーネル関数

- `tcp_retransmit_skb`
- `tcp_fastretrans_alert`
- `tcp_receive_reset`

これらの関数に kprobe を設置し、再送発生時にイベントを取得する。

---

## 取得する情報

- 送信元 / 宛先 IP
- 送信元 / 宛先ポート
- プロセス ID
- プロセス名
- 再送発生時刻
- 再送回数

---

## 開発ステップ

### Step 1: 基本的な eBPF プログラム作成
- kprobe を設置しイベントをログ出力

### Step 2: Go からリングバッファを読み取る
- eBPF → Go へのイベント転送

### Step 3: 再送イベントの構造化
- IP / ポート / PID 単位で集計

### Step 4: CLI でリアルタイム表示
- 再送数のライブ表示

### Step 5: Prometheus エクスポート対応
- 時系列可視化を可能にする

---

## 期待される成果

- 現代ネットワークにおける TCP 再送の実態の可視化
- eBPF と Go を用いた観測ツールの実装経験
- Linux TCP スタックへの深い理解
- 実務レベルの可観測性ツールの開発スキル

---

## ゴール

最終的に、

> 任意の Linux マシン上で動作し、TCP 再送の発生状況をリアルタイムで可視化できるツール

を完成させる。
